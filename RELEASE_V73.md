# GS Documentos v73

Corrección de renderizado PDF sobre la base oficial v72, sin devolver cambios funcionales.

- Se conserva la independencia actual entre Garrawall y arriostre.
- Se conserva la lista vigente de Documentos pendientes, incluida la opción "Todos los documentos fueron entregados".
- E1, E6, AR, DJ y RETIE se convierten en salida final aplanada y vectorial para evitar pérdida de letras o elementos al abrirlos en distintos visores.
- La Constancia TD se aplanará antes de exportarse para evitar superposición de campos.
- Se retira el postproceso legado v60 del TD, ya innecesario y potencialmente conflictivo.
- Caché PWA renovada a v73.
- Android: versionCode 73 y versionName 73.0; se mantiene la firma release estable.
