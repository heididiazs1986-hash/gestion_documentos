# GS Documentos v50

- Selector obligatorio de contrato al inicio de jornada: APPLUS+ / INMEL Ingeniería S.A.S.
- El contrato no cambia la identidad visual de GS Documentos; solo cambia el aliado en autorización de datos y la plantilla EC.
- Dos EC embebidos en Base64 y seleccionados automáticamente por contrato.
- Usuario + Predio unificados en una sola etapa para reducir pantallas sin volver al scroll eterno.
- Aceptación de requisitos (AR) restaurada en Documentos a generar. Constancia TD siempre automática y Doc. Electricista nunca aparece como documento generable.
- Documentos pendientes y Condiciones de seguridad persisten como multiselección y se exportan en una sola columna cada uno.
- Firmas a pantalla completa con vista previa, Repetir y Confirmar; visor para técnico y usuario.
- Nombre del técnico se normaliza como nombre propio.
- ZIP individual: documentos seleccionados + Constancia TD; usa compartir nativo cuando está disponible.
- Cierre de jornada: un ZIP con Excel + TD de usuarios sin ZIP individual; APPLUS+ agrega JSON SharePoint. INMEL no genera JSON SharePoint.
- ID_REGISTRO continúa como UUID local independiente del celular.
- Identidad móvil corregida: icono GS Documentos, menú desplegable en celular y mejor adaptación al ancho.
- Crédito: Desarrollado por Heidi Diaz para el proceso de gestión social.
